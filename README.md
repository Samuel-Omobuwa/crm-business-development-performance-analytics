# CRM & Business Development Performance Dashboard

## Project Overview
This project uses Power BI to analyse CRM data and monitor business development performance at Optiva Capital Partners. It focuses on lead conversion, officer productivity, branch performance, pipeline management, and data quality, transforming raw operational data into actionable insights for management.

## Business Problem
Inconsistent CRM records, limited pipeline visibility, and inadequate follow-up monitoring can hinder lead conversion and business performance. This project addresses these challenges through structured data cleaning, performance analysis, and interactive reporting.

## Objectives
- Improve CRM data quality and reliability.
- Track leads across pipeline stages and measure conversion rates.
- Evaluate officer productivity and branch performance.
- Identify ageing leads and overdue follow-ups.
- Provide management with actionable, data-driven recommendations.

## Tools & Technologies
- **Power BI:** Interactive dashboards and reporting.
- **Power Query:** Data cleaning and transformation.
- **DAX:** Dynamic KPI calculations and performance metrics.
- **Excel / CSV:** Source data validation and preparation.

## Data Sources
- `Officers.csv` — Officer details and roles.
- `Leads.csv` — CRM lead and pipeline records.
- `Daily Activities.csv` — Officer engagement and activity logs.
- `Data Dictionary.xlsx` — Field definitions and validation rules.

## Methodology
1. **Data Cleaning:** Identify duplicates, missing values, inconsistent formats, invalid dates, and pipeline errors.
2. **Data Analysis:** Examine lead distribution, conversion trends, officer activities, and data quality issues.
3. **Data Modelling:** Establish table relationships and create dynamic DAX measures.
4. **Dashboard Development:** Build interactive Power BI visuals for performance monitoring and management reporting.

## Key Dashboard Metrics
- Total Leads, Prospects, Clients, and Lost Leads.
- Lead-to-Prospect and Prospect-to-Client Conversion Rates.
- Branch Performance and Officer Leaderboards.
- Pipeline Distribution and Lead Ageing.
- Officer Activity and Follow-up Monitoring.
- CRM Data Quality Issues and Trends.

## Business Questions
The dashboard answers key questions, including:
- Which branches achieve the highest conversion rates?
- Which officers consistently perform best?
- Where are CRM data quality issues concentrated?
- Which leads require immediate follow-up?
- Which officers have the oldest unresolved pipeline items?
- What actions can improve conversion and operational efficiency?

## Business Value
The solution provides improved visibility into business development performance, supports proactive follow-up, strengthens CRM data reliability, and enables management to identify performance gaps and make informed operational decisions.
